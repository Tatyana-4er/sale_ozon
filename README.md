SELECT 
    TO_CHAR(DATE_TRUNC('month', TO_TIMESTAMP(date_of_receipt, 'DD.MM.YYYY HH24:MI')), 'YYYY-MM') AS sales_month
   ,COUNT(order_num) AS total_orders
   ,ROUND(SUM(CASE WHEN status = 'Доставлен' THEN CAST(order_amount AS NUMERIC) ELSE 0 END), 2) AS total_revenue
FROM DATA
GROUP BY sales_month
ORDER BY sales_month

Изучим недельные циклы: в какие дни люди чаще покупают дверную фурнитуру?

```sql
SELECT  CASE to_char(to_timestamp(date_of_receipt, 'DD.MM.YYYY'), 'ID')
        WHEN '1' THEN 'Понедельник'
        WHEN '2' THEN 'Вторник'
        WHEN '3' THEN 'Среда'
        WHEN '4' THEN 'Четверг'
        WHEN '5' THEN 'Пятница'
        WHEN '6' THEN 'Суббота'
        WHEN '7' THEN 'Воскресенье'
    	END AS day_name
       , COUNT (DISTINCT order_num) as cnt_order
FROM data
WHERE status = 'Доставлен'
GROUP by day_name
ORDER BY cnt_order desc
```

Основная покупательская активность приходится на будни. Пик приходится на середину недели, когда Среда и Четверг  становятся абсолютными лидерами по числу заказов. К выходным дням, начиная уже с пятницы спрос резко падает. Такой график указывает на профессиональных покупателей (мастеров) или розничных клиентов, планирующих ремонт и закупку фурнитуры заранее. Для бизнеса это повод усилить выгрузку склада в пиковые дни. Маркетинговую рекламу эффективнее запускать во вторник и среду, а для стимуляции просевших выходных можно протестировать специальные субботние скидки.

Исследуем динамику выручки каждой отдельной категории товара:

```sql
SELECT TO_CHAR(TO_TIMESTAMP(date_of_receipt, 'DD.MM.YYYY HH24:MI'), 'YYYY-MM') AS sales_month
    , SUM (CASE WHEN category = 'Ручки раздельные' THEN order_amount ELSE 0 END) AS "Ручки раздельные"
    , SUM (CASE WHEN category = 'Завертки/накладки' THEN order_amount ELSE 0 END) AS "Завертки/накладки"
    , SUM (CASE WHEN category = 'Кнобы (ручка+защелка)' THEN order_amount ELSE 0 END) AS "Кнобы (ручка+защелка)"
    , SUM (CASE WHEN category = 'Петли' THEN order_amount ELSE 0 END) AS "Петли"
    , SUM (CASE WHEN category = 'Ограничители' THEN order_amount ELSE 0 END) AS "Ограничители"
    , SUM (CASE WHEN category = 'Механизмы+цилиндры' THEN order_amount ELSE 0 END) AS "Механизмы+цилиндры"
    , SUM (CASE WHEN category = 'Раздвижные системы' THEN order_amount ELSE 0 END) AS "Раздвижные системы"
FROM DATA
WHERE status = 'Доставлен'
GROUP BY sales_month
ORDER BY sales_month;
```
| Месяц (`sales_month`) | Ручки раздельные | Завертки/накладки | Кнобы (ручка+защелка) | Петли | Ограничители | Механизмы+цилиндры | Раздвижные системы |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **2026.02** | 403 952 | 317 056 | 248 917 | 128 870 | 84 593 | 62 698 | 0 |
| **2026.03** | 610 777 | 385 258 | 169 739 | 171 573 | 74 026 | 68 270 | 0 |
| **2026.04** | 478 506 | 323 087 | 159 640 | 110 085 | 71 182 | 69 570 | 0 |
| **2026.05** *(Пик с рекламой)* | **613 876** | 333 282 | **275 742** | 118 991 | 122 583 | 58 211 | 1 668 |
| **2026.06** *(Отключение)* | **289 308** | 201 630 | **81 260** | **67 000** | 87 403 | 59 892 | 3 610 |
| **2026.07** *(Органика)* | 361 313 | 154 564 | **40 030** | **72 760** | 14 805 | 43 506 | 0 |

  Категория "Ручки раздельные" является главным источником выручки бренда. В мае на фоне работающей рекламы она принесла **613 876 руб.**, но в первый же месяц после её отключения (июнь) рухнула до **289 308 руб.** В июле начался слабый органический откат вверх (361 313 руб.), однако позиции карточек в выдаче Ozon остаются критически низкими по сравнению с весенним пиком.

   Категория готовых комплектов "ручка+защелка" пострадала сильнее всех. Выручка сократилась с **275 742 руб.** в мае до катастрофических **40 030 руб.** в июле (падение почти в 7 раз). Это доказывает, что кнобы на маркетплейсе покупаются импульсивно со страниц первой рекламной выдачи. На чистой органическом трафике эта категория практически перестала существовать.

   Технический ассортимент продемонстрировал феноменальную устойчивость к отсутствию продвижения:
   * Выручка по **"Механизмам+цилиндрам"** в июне даже немного выросла (с 58 211 до 59 892 руб.) и плавно снизилась в июле.
   * Продажи **"Петель"** после проседания в июне (67 000 руб.) в июле полностью отыграли падение, поднявшись до **72 760 руб.**
     *Вывод:* Мастера и целевые покупатели ищут замки и петли по строгим техническим параметрам и артикулам, листая выдачу глубоко вниз. Реклама на эти позиции тратила бюджет впустую.

### 💡 Стратегические рекомендации для коммерческого директора:
* **Признать эксперимент тотального отключения рекламы неэффективным:** Экономия на продвижении обернулась потерей миллионов рублей оборота на высокомаржинальном товаре.
* **Внедрить гибридную стратегию продвижения:** Срочно вернуть рекламные бюджеты исключительно на визуальные категории-локомотивы (**"Ручки раздельные"** и **"Кнобы"**), так как они не способны жить без трафика. Технический ассортимент (**"Петли"**, **"Механизмы"**) оставить на органическом поиске, сэкономив деньги компании.
